# AD ASTRA

**AD ASTRA**는 tick 기반 우주 식민지 경영 게임입니다. 플레이어는 하나의 모행성에서 시작해 주변 성계를 탐사하고, 행성을 식민화하고, 자원 생산 시설을 건설하고, 시장에서 자원을 사고팔며, 별자리 형태의 기술 트리를 연구합니다. 목표는 제국을 빠르게 키우되 부채, 유지비, 불안정, 시장 충격 때문에 무너지지 않게 운영하는 것입니다.

English guide: [README.md](README.md)

---

## 데모 실행

(1) Docker 이미지 받기
```bash
docker pull --platform linux/amd64 team12/adastra:0.1.0
```

(2) 게임 실행

Option A — 자동 실행:
```bash
bash scripts/run.sh
```
컨테이너가 시작되고 곧바로 `build/main`을 실행합니다.

Option B — 컨테이너에 먼저 들어간 뒤 수동 실행:
```bash
bash scripts/run_shell.sh
```
컨테이너 안의 bash shell로 들어갑니다. 컨테이너 내부에서 직접 다음 명령을 실행할 수 있습니다.

```bash
./build/main
```

(3) 웹 브라우저
http://localhost:6080/vnc.html

## 어떤 게임인가요?

AD ASTRA는 전투가 없는 4X풍 경제 식민지 게임입니다.

- **Explore**: 주변 성계를 탐사합니다.
- **Expand**: 항법 범위 안의 행성을 식민화합니다.
- **Exploit**: 행성 자원, 건물, 무역으로 경제를 키웁니다.
- **Endure pressure**: 불안정, 부채, 시장 충격, 제재, 해적, 지역 위기를 견딥니다.

함대 전투로 적을 제거하는 게임이 아닙니다. 핵심은 성장 속도와 재정 안정성 사이의 균형입니다.

---

## 캠페인 목표

캠페인은 정해진 tick 구간 동안 평가됩니다. 좋은 제국은 보통 다음 특징을 가집니다.

- 여러 개의 식민지.
- 다양한 자원 기반.
- 단기 충격을 버틸 수 있는 credits.
- 생산적 성장에 사용된 관리 가능한 부채.
- 꾸준한 연구 진행.
- 잉여 생산을 credits로 바꾸는 무역 경로.
- 낮은 불안정과 통제 가능한 위기 압력.

점수는 단순히 돈만 많다고 높아지지 않습니다. 성장, 안정성, 생산력, 기술, 재정 운영이 함께 중요합니다.

## 메인 지도

메인 화면은 3D 별 지도입니다. 행성 노드, 격자, 라벨, 경로 표시를 통해 제국의 위치와 확장 방향을 읽습니다.

지도 조작:

| 입력 | 동작 |
| --- | --- |
| 행성 좌클릭 | 선택 / 확인 |
| 좌클릭 드래그 | 지도 회전 |
| 우클릭 또는 휠 클릭 드래그 | 지도 이동 |
| 마우스 휠 | 확대 / 축소 |
| Esc | 오버레이 닫기 또는 일시정지 메뉴 |
| 일시정지 메뉴에서 Esc | 게임 종료 |

지도는 거리, 확장 후보, 경로 구조, 식민지 상태를 읽는 화면입니다.

## 자원

제국은 여러 자원으로 운영됩니다.

- **Credits (CR)**: 건설, 식민화, 시장 거래, 대출 상환, 위기 대응에 쓰이는 돈.
- **Iron (Fe)**: 기본 산업 자원.
- **Food (Fd)**: 식민지 유지와 안정에 필요한 식량.
- **Fuel (Fu)**: 확장, 물류, 함선 운용에 필요한 연료.
- **Rare materials (Ra)**: 고급 전략 자원.
- **Energy (En)**: 고급 시설에 필요한 에너지.
- **Alloy (Al)**: 고급 산업 생산물.
- **Research (RP)**: 기술 연구 자원.

행성마다 풍부한 자원이 다릅니다. 좋은 플레이는 행성 특성에 맞는 건물을 짓고, 부족한 부분은 시장과 무역으로 보완하는 것입니다.

---

## 식민화

식민화는 제국을 확장하지만 비용과 위험도 함께 늘립니다.

식민화 전 확인할 것:

- 거리와 항법 기술 범위.
- 식민화 비용.
- 향후 유지비.
- 목표 행성의 자원 가치.
- 현재 credits 여유.
- 그 행성이 실제 병목을 해결하는지.

가능한 모든 행성을 바로 먹는 것이 정답은 아닙니다. 필요한 자원을 주고, 감당 가능한 행성을 고르는 것이 중요합니다.

---

## 건물

건물은 식민지의 역할을 결정합니다.

주요 역할:

- **광산 / 추출 시설**: 원자재 생산.
- **농장**: 식량 생산.
- **산업 시설**: 자원을 고부가가치 생산물로 전환.
- **연구 시설**: 기술 연구점 생산.
- **무역 시설**: 시장 가치와 수출 능력 강화.
- **물류 시설**: 경로와 작전 범위 지원.

대부분의 건물에는 유지비가 있습니다. 나중에 강력한 건물도 경제 기반이 약할 때 지으면 파산의 원인이 될 수 있습니다.

---

## Macro Builder

Macro Builder는 제국 전체의 건설 후보를 비교하는 도구입니다. 행성을 하나씩 열어보지 않고도 다음 정보를 볼 수 있습니다.

- 건설 비용.
- 부족 자원.
- 예상 가치.
- 후보 행성.
- 전략적 의미.

여러 식민지를 보유한 중반 이후에는 Macro Builder를 중심으로 건설 계획을 세우는 것이 좋습니다.

---

## 시장과 무역

시장은 부족한 자원을 사거나 잉여 자원을 팔아 credits를 확보하는 수단입니다.

좋은 습관:

- 유동성이 필요할 때 잉여 자원을 판매합니다.
- 중요한 행동을 열 수 있을 때만 부족 자원을 구매합니다.
- 대형 건설이나 식민화 전에는 예비 자금을 남깁니다.
- 시장 충격과 가격 변화를 확인합니다.

시장은 강력하지만, 영원히 수입에 의존하는 경제는 위험합니다.

---

## 부채와 신용등급

대출은 곧 실패가 아닙니다. 부채는 확장과 건설을 앞당길 수 있지만 이자 부담과 만기 위험을 만듭니다.

확인할 것:

- 현재 credits.
- 총 부채.
- 이자 부담.
- 신용등급.
- 예비 자금 예측.

좋은 부채는 미래 수입을 만듭니다. 나쁜 부채는 붕괴를 늦출 뿐입니다.

---

## 연구

기술 트리는 별자리 형태로 표시됩니다. 노드는 잠김, 연구 가능, 연구 중, 완료 상태를 가집니다.

연구는 다음을 가능하게 합니다.

- 생산력 향상.
- 식민화 범위 증가.
- 새 건물 해금.
- 시장과 물류 강화.
- 경제 병목 해소.

가장 좋은 연구는 지금 제국을 막고 있는 문제를 해결하는 연구입니다.

---

## 이벤트와 압박

AD ASTRA의 긴장은 전투가 아니라 경제와 사회 압박에서 옵니다.

- 불안정과 반란 위험.
- 소행성 피해.
- 무역 호황과 폭락.
- 해적.
- 제재.
- 경쟁 무역 블록.
- 지역 위기.

일부 위기는 순찰, 외교 사절, 구호 조치로 대응할 수 있습니다. 대응에는 비용이 들지만 방치하면 더 큰 손실이 생길 수 있습니다.

---

## 튜토리얼

튜토리얼은 슬라이드쇼처럼 진행됩니다. 현재 설명에 필요한 만큼만 게임 tick을 진행한 뒤 입력을 기다립니다.

튜토리얼 버튼:

- **OK / NEXT**: 계속 진행.
- **Skip**: 현재 단계만 건너뛰기.
- **End**: 튜토리얼 완전히 종료.

지도, 시장, 건설, 연구 화면이 낯설다면 튜토리얼을 먼저 진행하는 것이 좋습니다.

## 전략 팁

1. 행성 수가 아니라 필요한 자원을 기준으로 확장하세요.
2. 대형 프로젝트 전에는 credits 예비금을 남기세요.
3. 시장은 부족분을 메우는 도구이지, 생산 기반의 대체물이 아닙니다.
4. 현재 병목을 해결하는 기술을 연구하세요.
5. 부채는 미래 수입을 만들 때만 좋은 선택입니다.
6. 불안정은 커지기 전에 잡는 것이 훨씬 쉽습니다.
7. 식민지가 여러 개가 되면 Macro Builder를 적극적으로 사용하세요.
